Publish Standard Packages

Publish signed releases with spkg publish and document your package with a plain-text <pkg>/README.md. Raw HTML/JS files inside package folders are blocked by CI.

publish.sh 
SPID3R_SIGN_KEY=<64-hex-seed> spkg publish --to-dir ./spid3r-spkg.github.io
# Add optional docs:
#   <pkg>/README.md
