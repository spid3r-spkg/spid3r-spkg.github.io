Publish, Mirror & Self-Host

Any static HTTP(S) host serves this registry format. Add fallback mirrors in spid3r.ini or set moved_to in registry.toml.

SPID3R_SIGN_KEY=<64-hex-seed> spkg publish --to-dir ./registry

# Multiple fallback mirrors in spid3r.ini:
# registry = https://pkg.example.com,https://spid3r-spkg.github.io
