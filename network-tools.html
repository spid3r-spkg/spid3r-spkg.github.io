Reference & Technical Notes

    Spid3r Local Companion Agent (Optional)

    Browser sandboxes cannot send raw ICMP Echo packets, open arbitrary TCP ports, or read local OS ARP/routing/socket tables. Install the signed nettools package and run its loopback-only Spid3r server to enable live OS command execution: 

    spkg install nettools
spid3r run vendor/nettools/src/server.matrix
